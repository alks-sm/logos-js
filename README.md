# Logos

Фреймворк кристаллизации архитектуры и разработки «сверху вниз» ([ДРАКОН](https://github.com/alks-sm/drakon-js) + [Дорожки](https://github.com/alks-sm/lanes-js) + Исполняемый скелет `Logos.Runtime`) для управления разработкой с ИИ.

Вместо прозы в разрозненных `.md`-файлах система задаёт программу на **двух уровнях** (подробно в [docs/architecture.md](docs/architecture.md) и [docs/decisions/README.md](docs/decisions/README.md)):
1. **Макро-уровень («Завод»):** словарь терминов (`terms`), решения (`decisions`), инварианты со стражами кода (`invariants`), слои и модули (`modules`), разъёмы плагинов (`sockets`), межмодульные протоколы (`lanes-js`) и глобальный автомат состояний (`states`).
2. **Микро-уровень («Цех узла», УА + ОА):** регистры состояния и шага (`1-schema.js`), управляющий план на ДРАКОНе (`2-plan.js`), паспорта колбэков с тестами (`3-contracts.js`) и чистые функции реализации (`impl/{guards,steps,ports}.js`) под защитой `deepFreeze` (0 скрытых состояний).

| Файл / Каталог | Что это |
|---|---|
| `logos.js`, `logos.css` | ядро Макро-уровня: конструкторы модели, `Logos.lint`, мультиязычный сканер `Logos.verifyRepo`, авто-съём `Logos.discoverRepo`, SVG-схемы слоёв и состояний, `Logos.brief` / `Logos.judge` |
| `runtime.js` | ядро Микро-уровня (`Logos.Runtime`): исполнение схем ДРАКОН по колбэкам с `deepFreeze`, запись ленты тактов (`trace`) и верификатор `verifySkeleton` |
| `logos-api.js`, `mcp-server.js` | единый командный слой (проверка до записи М11, генератор проектов `scaffoldProject`, симуляция) и MCP-сервер по `stdio` (`.mcp.json`) |
| `cli.js`, `hooks/`, `skill/` | консольный интерфейс, хуки для `claude` CLI / Git и навык `logos` |
| `index.html`, `mockups.html` | интерактивный пульт Главного Конструктора и сравнение 3 концептов UI (выбран Вариант В: «ДРАКОН + Лента тактов + Таблица регистров») |
| `examples/keel-model.js`, `examples/nav-skeleton/` | эталонная модель макро-архитектуры **Keel** и эталонный исполняемый узел навигации окна |
| `docs/architecture.md`, `docs/decisions/` | полное описание двухэтажной модели и реестр принятых решений `0001`–`0008` |

## Команды CLI

```bash
npm test                                    # тесты ядра Logos и отчёт по модели Keel
node cli.js check                           # полная проверка модели и репозитория + снимок для UI
node cli.js init <путь-к-репозиторию>       # детерминированный съём существующего проекта (TS/JS, Kotlin, Go, Python, .NET)
node cli.js verify-unit [папка-узла]        # проверка узла «Скелет + Колбэки» (привязки ДРАКОН, тесты, чистота impl/)
node cli.js slot-brief <slotId> [папка]     # выгрузить изолированное микро-ТЗ на одно гнездо колбэка
node cli.js simulate [scenarioId] [папка]   # прогнать сценарий через исполняемую схему ДРАКОН
node cli.js scaffold <папка> <id> [название]# создать с нуля новый проект со скелетом, моками и автотестом
```
