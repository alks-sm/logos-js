# Logos

Формальная база архитектуры, инвариантов, границ модулей, состояний и схем ([ДРАКОН](https://github.com/alks-sm/drakon-js) + [Дорожки](https://github.com/alks-sm/lanes-js)) для управления разработкой с ИИ.

Вместо прозы в разрозненных `.md`-файлах (где нейросети допускают вольные трактовки и спорят на ревью) правила проекта описываются как единая проверяемая модель данных:
1. **Законы:** принятые решения (`decision`), инварианты со ссылками на автоматические стражи (`invariant` + `guard`) и словарь терминов (`term`).
2. **Границы и расширяемость:** слои и модули (`moduleDef`) + официальные разъёмы под плагины (`socket` — например, для `Frame Generator` или генератора шестерёнок).
3. **Автомат состояний:** состояния (`state`) и переходы (`transition`) с проверкой достижимости, отсутствия тупиков и возврата по `Esc`.
4. **Протоколы во времени (`lanes-js`):** взаимодействие между человеком, окном, командным слоем, плагинами, ядром и хранилищем.
5. **Алгоритмы (`drakon-js`):** блок-схемы ДРАКОН (примитивы и силуэты) со сквозной проверкой вставок `ins`.

| Файл | Что это |
|---|---|
| `logos.js` | ядро: конструкторы модели, сквозной верификатор `Logos.lint`, SVG-схемы слоёв (`layersSvg`) и состояний (`statesSvg`), генератор ТЗ для ИИ (`Logos.brief`), справка `Logos.help` |
| `logos.css` | стили схем и карточек (`--lg-*`, светлая и тёмная тема) |
| `vendor/drakon.*`, `vendor/lanes.*` | встроенные движки блок-схем ДРАКОН и схем «дорожки и время» |
| `examples/keel-model.js` | эталонный срез архитектуры CAD-системы **Keel** |
| `index.html` | интерактивный пульт Главного Конструктора (работает и с `file://`, и через HTTP) |
| `test.js` | автотесты ядра `Logos` и проверка модели `Keel` |

## Команды

```bash
npm test          # прогнать тесты ядра Logos и отчёт по модели Keel
npm run lint:keel # вывести сводный отчёт проверки Keel в консоль
npm run help      # встроенная справка Logos.help('all')
```

## Смотреть в браузере

Открыть `index.html` напрямую файлом в браузере или поднять статический сервер в этой папке.
