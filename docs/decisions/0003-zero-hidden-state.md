# 0003. Запрет на скрытые состояния по построению

**Статус:** принято

## Контекст
Главный источник трудноуловимых ошибок в коде, написанном нейросетями, — размазывание мутабельного состояния по модульным переменным (`let`), полям классов (`this.x`) и дублирующим флагам, которые забывают обновить при очередном переходе.

## Решение
Скрытые состояния делаются **физически невозможными** тремя механизмами:
1. **Глубокая заморозка (`deepFreeze`) в `Logos.Runtime`:** перед передачей в любой колбэк объекты `state`, `bag` и `world` рекурсивно замораживаются через `Object.freeze`. Любая попытка мутировать поле на месте вызывает немедленный `TypeError`.
2. **Производное вычисляется (`derived`):** данные, которые однозначно следуют из других полей состояния (например, `modeOf(state)`), запрещено хранить в `State` — они описываются чистыми функциями в `1-schema.js`.
3. **Страж чистоты `impl/`:** верификатор сканирует исходники `impl/*.js` и блокирует наличие `let`, `var`, `class`, `this` и прямых обращений к `window`/`document`.

## Следствия
* Любой шаг исполнения детерминирован и зависит только от входного снимка регистров `(state, bag, world)`.
* Воспроизведение любого бага сводится к подстановке входного JSON-снимка в сценарий `1-schema.js`.
